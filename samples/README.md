# Samples

Put the videos of old apps here, each with an optional hand-written spec next to it:

```
samples/my-old-site.mp4
samples/my-old-site.json   # used by --reader spec-file
```

Videos are not committed. Only use apps we have the rights to: our own old projects, open source apps, or sites whose owner agreed. No clones of well-known brands presented as a finished product.
